Reporte responsable de seguridad

Kingdom agradece los reportes de vulnerabilidades reales o potenciales relacionados con este dominio web.

1. Canal de contacto

Envía reportes a kingdombrandbqto@gmail.com. No incluyas credenciales, secretos, datos personales innecesarios ni información confidencial de clientes.

2. Archivo security.txt

De conformidad con las buenas prácticas de divulgación responsable (RFC 9116), este sitio mantiene publicado el archivo de política de seguridad en: /.well-known/security.txt.

3. Contenido del reporte

Incluye la URL afectada, descripción técnica clara, impacto observado, pasos mínimos y reproducibles, evidencia no sensible y, cuando corresponda, una recomendación de mitigación.

4. Reglas de investigación

No interrumpas servicios, no alteres ni elimines datos, no accedas a información de terceros, no realices ingeniería social, no uses fuerza bruta y no divulgues públicamente una vulnerabilidad antes de coordinar razonablemente su tratamiento con Ramses Martínez.

5. Respuesta

Confirmaremos la recepción del reporte y evaluaremos su severidad para aplicar las correcciones técnicas pertinentes en el menor tiempo razonable.

6. Arquitectura de seguridad y hosting

Este sitio se publica en GitHub Pages como un entorno estático sin backend, bases de datos activas ni procesamiento de sesiones o contraseñas.

Debido a las limitaciones propias de la infraestructura de GitHub Pages, las cabeceras HTTP de respuesta a nivel de servidor como X-Frame-Options, Content-Security-Policy: frame-ancestors y Strict-Transport-Security (HSTS) no están activas.

La protección en el navegador se gestiona mediante la etiqueta <meta http-equiv="Content-Security-Policy">, la cual mitiga ataques de Cross-Site Scripting (XSS), inyecciones de código y carga de recursos no autorizados (restringiendo scripts, estilos, conexiones y objetos exclusivamente al propio origen y a endpoints autorizados de analítica bajo consentimiento). El archivo _headers se mantiene reservado para una eventual migración a infraestructura con soporte perimetral.
