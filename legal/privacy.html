Política de privacidad

Este documento explica cómo se trata la información relacionada con el sitio web de Kingdom y con las vías de contacto que una persona decide utilizar.

Nota: este documento describe la configuración actual del sitio y no sustituye asesoría jurídica. Debe revisarse cuando cambien el negocio, los proveedores, los mercados atendidos o la legislación aplicable.

2. Qué hace actualmente este sitio

La versión actual del sitio es un portafolio estático informativo. No contiene un formulario propio de registro, no solicita contraseñas, no integra un sistema de cuentas y no realiza seguimiento publicitario de terceros. Opcionalmente, incorpora métricas de uso anónimas mediante Google Analytics únicamente tras la aceptación previa y expresa del visitante.

Las interacciones de contacto disponibles en la página abren servicios externos, como WhatsApp, correo electrónico, redes sociales o almacenamiento externo. Al continuar hacia uno de esos servicios, el tratamiento de los datos queda sujeto también a las condiciones y políticas del proveedor correspondiente.

3. Datos que una persona puede proporcionar voluntariamente

Cuando una persona decide contactar a Kingdom puede comunicar, entre otros, nombre, empresa, datos de contacto, detalles del proyecto, referencias visuales, especificaciones técnicas o información necesaria para preparar una cotización. Kingdom solo solicita la información estrictamente necesaria para atender la consulta.

4. Finalidades

La información comunicada voluntariamente se utiliza para responder consultas, preparar cotizaciones, coordinar proyectos, prestar servicios solicitados y cumplir obligaciones legales aplicables.

5. Base jurídica y derechos

La base jurídica para atender consultas y cotizaciones es la adopción de medidas precontractuales o contractuales a solicitud del interesado, así como el consentimiento para comunicaciones directas. Para las métricas analíticas opcionales, la base es el consentimiento informado del usuario.

Para ejercer derechos de acceso, rectificación, supresión o revocación de consentimientos, puede escribir a: kingdombrandbqto@gmail.com.

6. Conservación

Los datos de consultas y cotizaciones se conservan durante el plazo necesario para atender la relación comercial y dar cumplimiento a responsabilidades legales o contractuales pertinentes, procediéndose a su eliminación una vez cumplida su finalidad.

7. Proveedores externos

La página dirige a servicios de terceros, actualmente identificados como WhatsApp, Instagram, LinkedIn, TikTok, correo electrónico y Google Drive. Esos servicios tratan la información conforme a sus propias políticas de privacidad. Kingdom no asume control sobre el tratamiento efectuado internamente dentro de dichas plataformas externas.

8. Transferencias internacionales

Los proveedores tecnológicos utilizados para comunicaciones o alojamiento (como GitHub, Google o Meta) pueden operar infraestructura en distintas jurisdicciones bajo sus correspondientes marcos de transferencia y garantías de privacidad.

9. Seguridad

El sitio utiliza una arquitectura estática con una superficie de ataque reducida y una política de seguridad de contenido estricta. Esto disminuye riesgos técnicos, pero ninguna medida técnica elimina por completo el riesgo. El canal de comunicación de seguridad se publica en Seguridad.

10. Cambios

Esta política puede actualizarse cuando cambien las funcionalidades técnicas, proveedores o exigencias regulatorias. La fecha de versión se indicará al inicio del documento.
