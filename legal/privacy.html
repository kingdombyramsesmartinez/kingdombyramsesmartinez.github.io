Política de privacidad

Este documento explica cómo se trata la información relacionada con el sitio web de Kingdom y con las vías de contacto que una persona decide utilizar.

Nota: este documento describe la configuración actual del sitio y no sustituye asesoría jurídica. Debe revisarse cuando cambien el negocio, los proveedores, los mercados atendidos o la legislación aplicable.

2. Qué hace actualmente este sitio

La versión actual del sitio es una landing page/portafolio estático. No contiene un formulario propio de registro, no solicita contraseñas, no integra un sistema de cuentas y no incorpora analítica publicitaria de terceros por defecto.

Las interacciones de contacto disponibles en la página abren servicios externos, como WhatsApp, correo electrónico, redes sociales o almacenamiento externo. Al continuar hacia uno de esos servicios, el tratamiento de los datos queda sujeto también a las condiciones y políticas del proveedor correspondiente.

3. Datos que una persona puede proporcionar voluntariamente

Cuando una persona decide contactar a Kingdom puede comunicar, entre otros, nombre, empresa, datos de contacto, detalles del proyecto, referencias visuales, especificaciones técnicas o información necesaria para preparar una cotización. Kingdom solo debería solicitar la información razonablemente necesaria para atender la consulta.

4. Finalidades

La información comunicada voluntariamente puede utilizarse para responder consultas, preparar cotizaciones, coordinar proyectos, prestar servicios solicitados, gestionar comunicaciones comerciales cuando exista una base jurídica válida y cumplir obligaciones legales aplicables.

5. Base jurídica y derechos

La base jurídica depende de la jurisdicción y del contexto. Cuando resulte aplicable el RGPD, pueden existir bases como medidas precontractuales, ejecución contractual, cumplimiento de obligaciones legales, interés legítimo o consentimiento, según el tratamiento concreto. El consentimiento debe ser específico, informado y revocable.

Cuando una normativa local otorgue derechos de acceso, rectificación, supresión, oposición, limitación, portabilidad u otros, Kingdom dispondrá de un canal razonable para atenderlos. Para solicitudes de privacidad: kingdombrandbqto@gmail.com.

6. Conservación

Los datos de consultas deberían conservarse solo durante el tiempo necesario para la finalidad correspondiente y para atender obligaciones legales, contables, contractuales o la defensa de derechos. El responsable debe definir internamente periodos concretos y eliminarlos de forma segura cuando dejen de ser necesarios.

7. Proveedores externos

La página dirige a servicios de terceros, actualmente identificados en la landing como WhatsApp, Instagram, LinkedIn, TikTok, correo electrónico y Google Drive. Esos servicios pueden recopilar o procesar información conforme a sus propias políticas. Kingdom no debe afirmar que controla el tratamiento efectuado dentro de esas plataformas.

8. Transferencias internacionales

Los proveedores utilizados pueden operar infraestructura en distintos países. Antes de publicar campañas dirigidas a regiones con obligaciones específicas, el responsable debe identificar proveedores, ubicaciones de datos, bases de transferencia y mecanismos jurídicos que correspondan.

9. Seguridad

El sitio utiliza una arquitectura estática con una superficie de ataque reducida y una política de seguridad de contenido estricta. Esto disminuye riesgos técnicos, pero ninguna medida de seguridad elimina por completo el riesgo. El correo de vulnerabilidades se publica en Seguridad.

10. Cambios

Esta política puede actualizarse cuando cambien las funcionalidades, proveedores o obligaciones legales. La fecha de versión se indicará al inicio del documento.
