Responsible Security Disclosure

Kingdom welcomes responsible disclosure reports regarding real or potential vulnerabilities relating to this web domain.

1. Contact Channel

Please send vulnerability reports to kingdombrandbqto@gmail.com. Do not include passwords, credentials, sensitive customer data, or unnecessary personal information.

2. Security.txt Specification

In accordance with responsible disclosure practices (RFC 9116), this website maintains its security contact policy at: /.well-known/security.txt.

3. Report Details

Please specify affected URL or asset, technical description, observed impact, minimal reproducible steps, non-sensitive proof of concept, and mitigation recommendations where applicable.

4. Rules of Engagement

Do not disrupt services, do not alter or delete data, do not access third-party accounts, do not perform social engineering, do not use brute-force attacks, and do not disclose vulnerabilities publicly prior to reasonable coordinated remediation with Ramses Martínez.

5. Response

We commit to acknowledging receipt, evaluating severity, and deploying necessary technical remediations in a timely manner.

6. Security Architecture and Hosting

This website is published on GitHub Pages as a static environment without backend databases, servers, or active user session processing.

Browser-level protection is configured through the <meta http-equiv="Content-Security-Policy"> directive, mitigating Cross-Site Scripting (XSS), code injection, and unauthorized resources by restricting scripts, styles, connections, and objects to verified origins. The _headers file remains reserved for potential future edge hosting migrations.
