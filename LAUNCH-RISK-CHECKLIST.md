# KINGDOM — CHECKLIST ANTES DE PUBLICIDAD PAGADA

## A. Identidad comercial
[ ] Nombre legal / razón social confirmado.
[ ] País, domicilio y correo legal confirmados.
[ ] Dominio propio adquirido y en HTTPS.
[ ] Registro de marca consultado en los mercados donde se usará de forma comercial.
[ ] Datos fiscales/empresariales listos para facturación y contratos.

## B. Portafolio y propiedad intelectual
[ ] Cada imagen tiene ficha interna de origen.
[ ] Cada trabajo de cliente tiene permiso contractual o escrito para mostrarlo en web/redes.
[ ] Logos de terceros usados de forma descriptiva o con autorización documentada.
[ ] Personajes, fotografías, tipografías y recursos externos tienen licencia o permiso suficiente.
[ ] No se afirma patrocinio, afiliación o aprobación de terceros sin evidencia.

## C. Claims / publicidad
Antes de activar anuncios, verifica con evidencia:
[ ] “Más de 10 años”.
[ ] “100+ matrices por mes”.
[ ] “60+ full print por mes”.
[ ] “reducción de roturas”.
[ ] “cero arrugas”.
[ ] “cero desperdicio”.
[ ] “primer nivel”.
[ ] cualquier porcentaje, garantía, “alta precisión”, “optimizado”, “calibrado” o resultado cuantificable.

Regla: si una frase comunica un resultado objetivo, guarda el soporte antes de publicarla.

## D. Privacidad
[ ] Política de privacidad completada con identidad real.
[ ] Correo de privacidad operativo.
[ ] Inventario de proveedores externos documentado.
[ ] Sin analítica/píxeles/cookies no esenciales sin el mecanismo de consentimiento correspondiente.
[ ] Procedimiento para solicitudes de derechos de privacidad.
[ ] Periodos de conservación definidos.

## E. Seguridad
[ ] DNS y dominio bajo proveedor confiable.
[ ] HTTPS activo.
[ ] HSTS activado solo cuando todos los subdominios necesarios funcionen por HTTPS.
[ ] `_headers` aplicado y verificado.
[ ] CSP validada en producción.
[ ] Backups/version control activos.
[ ] MFA activado en dominio, hosting, correo, Git y redes sociales.
[ ] Correo separado para seguridad (SECURITY@...).
[ ] security.txt accesible en /.well-known/security.txt.

## F. Contratación
[ ] Cotización con alcance, precio, moneda, impuestos, tiempos y revisiones.
[ ] Propiedad intelectual: cesión/licencia claramente definida.
[ ] Responsabilidad del cliente sobre material de terceros.
[ ] Confidencialidad/NDA cuando aplique.
[ ] Reglas de cancelación, reembolso, cambios y archivos fuente.
[ ] Autorización de portafolio separada o incluida contractualmente.
[ ] Jurisdicción y ley aplicable revisadas profesionalmente.

## G. Publicidad internacional
No presupongas que una sola política cubre todos los países. Revisa las obligaciones de los mercados objetivo antes de lanzar campañas específicas.

## H. Lanzamiento
[ ] Dominio final reemplazado en sitemap y documentos.
[ ] Links internos comprobados.
[ ] WhatsApp y correo comprobados.
[ ] OG image y metadatos sociales configurados con el dominio final.
[ ] Lighthouse / PageSpeed revisado.
[ ] Prueba en móvil, teclado y lector de pantalla.
[ ] Prueba de headers con un escáner HTTP.
[ ] Previsualización de anuncios comprobada.
